# E-CART System 🛒

A modern, responsive **e-commerce web application** built with React, TypeScript, Vite, Firebase, and Tailwind CSS.

## ✨ Key Features
- Product browsing and shopping workflows
- Responsive modern UI
- React component architecture
- Firebase-backed application services
- Client-side routing
- Interactive motion and icons
- Production-ready Vite build workflow

## 🛠️ Tech Stack
**React 19 · TypeScript · Vite · Tailwind CSS · Firebase · Express · React Router · Motion · Lucide React**

## 🚀 Run Locally
```bash
git clone https://github.com/PavanWadile77/E-CART-System.git
cd E-CART-System
npm install
npm run dev
```

Production:
```bash
npm run build
npm run preview
```

## 🔐 Security
Keep Firebase credentials and other secrets in environment configuration. Never commit private keys or service-account files.
