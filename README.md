# E-CART System 🛒

A modern web-based e-commerce application built with **React, TypeScript, Vite, Firebase, and Tailwind CSS**.

## Overview

E-CART System provides a foundation for browsing products, managing shopping workflows, and building a responsive digital commerce experience.

## ✨ Highlights

- Responsive e-commerce interface
- Product browsing and shopping workflow
- React-based component architecture
- Firebase integration
- Modern Tailwind CSS styling
- Client-side routing
- Motion and icon support
- Environment-based configuration

## 🛠 Tech Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS
- Firebase
- Express
- React Router
- Lucide React
- Motion

## ▶️ Run Locally

```bash
git clone https://github.com/PavanWadile77/E-CART-System.git
cd E-CART-System
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```

Type-check the project:

```bash
npm run lint
```

## 🔐 Environment Variables

Copy the example configuration and provide the required project values:

```bash
cp .env.example .env
```

Do not commit private credentials or production secrets.
